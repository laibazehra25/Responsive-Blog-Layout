# ✨ Radiance Landing Page

A stunning, conversion-optimized landing page for premium skincare products. Built with modern web technologies and designed with user experience in mind.

![Radiance Landing Page Preview](https://images.pexels.com/photos/30229017/pexels-photo-30229017.jpeg?cs=srgb&fm=jpg&w=800&dpr=1)

## 🌟 What is Radiance?

Radiance is a fictional premium skincare brand featuring a daily brightening serum. This landing page demonstrates how to create an engaging, professional product showcase that converts visitors into customers.

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML/CSS/JavaScript (for customization)

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/radiance-landing-page.git
   cd radiance-landing-page
   ```

2. Open `Radiance_LandingPage.html` in your browser
3. That's it! No build process or dependencies needed.

### Customization

#### Changing Colors
The color scheme is controlled by CSS custom properties in the `:root` selector:

```css
:root {
  --bg: #f8fafc;          /* Main background */
  --brand: #0ea5e9;       /* Primary brand color */
  --brand-2: #22c55e;     /* Secondary brand color */
  /* ... more variables */
}
```

#### Adding Your Content
- Replace the product images with your own
- Update the product description and features
- Modify the testimonials section
- Change the contact information

#### Theme Customization
The dark theme colors are defined in the `[data-theme="dark"]` selector:

```css
[data-theme="dark"] {
  --bg: #0e1a16;          /* Dark background */
  --brand: #84e1bc;       /* Dark mode brand color */
  /* ... more variables */
}
```
